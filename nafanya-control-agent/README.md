# Проверка сессии пульта Нафани

Здесь хранится изменённый модуль и тесты для отдельного сервиса управления Нафаней. Основной проект сервиса развёрнут на сервере в `/home/masha/nafanya-zoom-sender/control-agent/`; остальные его файлы живут там же.

Веб-пульт принимает отдельную долговременную cookie `pn_nafanya_staff`. Перед каждым запросом к пульту Node-сервис проверяет её через `/nafanya-auth-check` на основном сайте. Сайт сверяет хеш сессии с текущей учётной записью: аккаунт должен оставаться активным, а галочка доступа — включённой. При отключении доступа CMS удаляет сессии этого пользователя. Пароль повторно в пульт не передаётся.

Участник с включённым доступом получает обычные средства управления. Раздел «Админ / вход Zoom» и административные API остаются только у администраторов сайта, которым отдельно выдан доступ к пульту. Zoom App сохраняет свой отдельный способ проверки.

Проверки:

- `node --test nafanya-control-agent/staff-auth.test.mjs`
- `php tests/nafanya-auth.test.php`
