# Анонимные обращения → Telegram-группа

Отдельный бесплатный Cloudflare Worker для анонимных обращений с `pochtinormalnye.ru`, MAX и личных сообщений Telegram-боту. Служащие отвечают обычными сообщениями в отдельных темах закрытой Telegram-группы.

## Что уже настроено

- Worker: `pn-support-chat` (`https://pn-support-chat.pochtinormalnye.workers.dev`);
- браузер обращается к нему через `https://pochtinormalnye.ru/support-chat-api/`, чтобы чат работал в сетях, где `workers.dev` недоступен;
- D1: `pn-support-chat`
- хранение сообщений: 30 дней с последней активности;
- разрешённые сайты: только `https://pochtinormalnye.ru` и `https://www.pochtinormalnye.ru`;
- текст: до 2 000 символов;
- IP-адреса, имена, username, телефоны и почта в базе не сохраняются;
- Telegram chat ID хранится только в зашифрованном виде, а для поиска открытого диалога используется необратимый HMAC-отпечаток;
- ежедневная очистка: 02:17 UTC;
- токены и технические секреты хранятся только как Cloudflare Secrets; отдельный ключ переходника существует и на сервере, но не хранится в репозитории.

## MAX → Telegram

MAX-бот использует ту же закрытую Telegram-группу и создаёт одну тему на одно обращение. Оператор видит только источник и случайный номер обращения вида «MAX · Аноним XXXX»: имени, `@username`, телефона и данных профиля MAX в теме нет. Обращения сайта отмечены «Сайт · Аноним XXXX». В D1 остаётся только технический ID MAX, необходимый исключительно для доставки ответа.

1. В профиле MAX для партнёров создать и отправить на модерацию чат-бота. Для создания нужен верифицированный профиль организации, ИП или самозанятого.
2. После одобрения выполнить `npm run setup:max-token`, открыть одноразовый локальный адрес и вставить токен бота.
3. Скрипт сохранит токен и секрет в Cloudflare, развернёт Worker, а затем попросит уже Cloudflare (не ваш компьютер) подписать MAX на `https://pochtinormalnye.ru/support-chat-api/max/webhook`.
4. Проверить `/support-chat-api/health`: поле `maxConfigured` должно стать `true`.

Бот принимает только личные текстовые сообщения. Первое сообщение создаёт тему `MAX · Аноним XXXX`, ответ из Telegram-темы возвращается в MAX. `/close` работает и в MAX, и в Telegram-теме.

## Однократная настройка Telegram

1. В официальном `@BotFather` отправить `/newbot`.
2. Имя: `Связь с группой “Почти нормальные”`.
3. Адрес: `@PochtiNormalnye_help_bot`; если занят — `@PN_svyaz_bot`.
4. В `@BotFather` выполнить `/setprivacy`, выбрать нового бота и нажать **Disable**. Без этого Telegram будет прятать от бота обычные ответы служащих — весьма заботливо и совершенно некстати.
5. Создать закрытую группу `ПН — обращения с сайта` и включить **Темы**.
6. Добавить бота администратором. Ему нужны права отправлять/удалять сообщения и управлять темами; назначать администраторов и приглашать людей не нужно.
7. Выполнить `npm run setup:telegram-token`, открыть показанный локальный адрес и вставить токен в однократную форму. Она сама сохранит секрет, развернёт Worker и зарегистрирует webhook. Токен нельзя добавлять в файлы, Git или сообщения.
8. Дождаться на локальной странице сообщения `Готово ✓`.
9. В закрытой группе отправить `/bind` от Telegram-пользователя с ID, указанным в `OWNER_TELEGRAM_ID`.
10. Проверить `https://pochtinormalnye.ru/support-chat-api/health`: поля `telegramConfigured`, `telegramPrivateConfigured` и `operatorGroupBound` должны быть `true`.

## Telegram-пользователь → Telegram-группа

Пользователь открывает `@PochtiNormalnye_help_bot` и нажимает **Запустить**. `/start` показывает приветствие, но не создаёт пустую тему. Первое обычное текстовое сообщение создаёт тему `Telegram · Аноним XXXX`. В группе нет имени, `@username`, номера телефона, ссылки на аккаунт или пересланного оригинала сообщения.

Ответ служащего из темы бот доставляет пользователю в личный чат. Обычные Unicode-эмодзи и Telegram custom emoji сохраняются. Команда `/close` у пользователя или кнопка закрытия в теме завершает текущий диалог; следующее сообщение создаст новый случайный анонимный номер.

## Разработка и развёртывание

```powershell
npm install
npm run typecheck
npm test
npx wrangler d1 migrations apply pn-support-chat --local
npm run dev
```

Боевой выпуск:

```powershell
npx wrangler d1 migrations apply pn-support-chat --remote
npm run deploy
```

После изменения виджета нужно увеличить версии `site-chat.js`/`styles.css` в PHP-шаблонах и имя кеша в `sw.js`, затем проверить мобильную и компьютерную версии.

Конфигурация прокси хранится в `server/Caddyfile`: маршрут `/support-chat-api/*` снимает этот префикс и передаёт запрос Worker. Заголовок с адресом посетителя Worker принимает для антиспама только от IP сервера сайта.

## Живой тест

1. Открыть сайт в обычном и приватном окне.
2. Отправить из каждого окна разные сообщения.
3. Убедиться, что в Telegram создались две разные темы `Сайт · Аноним XXXX`.
4. Ответить обычным текстом в каждой теме и проверить, что ответы не перепутались.
5. Закрыть диалог кнопкой в Telegram и проверить уведомление на сайте.
6. Проверить повторную отправку после временного отключения сети и перезагрузку страницы.
7. В MAX написать боту, убедиться, что появилась тема `MAX · Аноним XXXX` без данных профиля; ответить из темы и проверить доставку в MAX.
8. Написать `@PochtiNormalnye_help_bot`, убедиться, что появилась тема `Telegram · Аноним XXXX`; ответить из темы и проверить доставку в личный Telegram.

## Важные команды

- `/bind` — привязать закрытую форум-группу (только владелец).
- `/start` — показать посетителю описание анонимного Telegram-чата.
- `/close` — закрыть текущий диалог из его темы.
- Кнопка `Закрыть диалог` под первым сообщением делает то же самое.

Нафаня, его токен, база и webhook этим проектом не используются и не изменяются.
