# Почти нормальные — сайт и лёгкая CMS

Публичные адреса сохраняются, а содержимое сайта выводится через лёгкую PHP-CMS:

- `announcements.html` — объявления;
- `schedule.html` — расписание;
- `library.html` — библиотека;
- `speakers.html` — спикерские;
- `service.html` — служения.
- `newcomers.html` — добавляемые и редактируемые страницы раздела «Новичкам»;
- `tradition.html` — тексты, казначей и реквизиты 7-й традиции;
- `/` — основной текст на главной странице;
- `/p/адрес` — произвольные страницы;
- меню, кнопки и быстрые ссылки также редактируются в CMS.

Редактор поддерживает форматирование, таблицы до 30 строк, кнопки, ссылки, изображения внутри текста, групповые эмодзи и отобранные изображения стандартных эмодзи из Telegram для Android. У телеграмовских эмодзи оставлен только базовый жёлтый вариант; профессии, еда, спорт, растения, животные, одежда, транспорт, флаги и другие ненужные для объявлений категории исключены. Тяжёлые пользовательские изображения автоматически уменьшаются в браузере перед отправкой.

## Первый запуск на Евробайт

1. Выбрать российную площадку **Москва** и тариф с PHP 8.2+ и минимум 3 ГБ места.
2. В панели хостинга включить PHP 8.2 или новее и бесплатный SSL Let's Encrypt.
3. Загрузить в корень сайта все файлы репозитория, **кроме** `.git`, `.agents`, `.codex`, `support-chat-worker`, `pochtinormalnye-site.zip` и `CNAME`.
4. Скопировать `cms-config.example.php` в `cms-config.php`; придумать и вставить секрет установки из 48+ случайных символов. Этот файл нельзя публиковать в Git или пересылать.
5. Убедиться, что PHP может записывать в папки `cms-data`, `cms-backups` и `uploads` (обычно достаточно прав 750 или 755, зависит от панели).
6. Открыть `https://ВАШ-ДОМЕН/setup.php`, ввести секрет и создать первый аккаунт администратора. После создания пользователя `setup.php` автоматически перестанет работать.
7. Войти на `https://ВАШ-ДОМЕН/admin/`, создать остальных пользователей и выдать права по разделам.
8. До смены DNS проверить тестовый адрес Евробайт, затем переключить домен. Не выключать прежний хостинг, пока сайт не проверен через Wi-Fi, мобильную сеть и другую российскую сеть.

## Безопасность и данные

- Пароли хранятся только как криптографические хеши.
- Администраторы управляют пользователями и их доступами. Редакторы видят только разрешённые разделы.
- JSON-данные, резервные копии и конфигурация закрыты правилами `.htaccess`.
- При каждом сохранении создаётся резервная копия; хранится 30 последних версий каждого файла.
- Не удаляйте `.htaccess`, `cms.php`, `public.php` и папку `cms-data`: это двигатель сайта, а не лишние гайки.

## Чат сайта

Плавающий чат на публичных страницах работает через отдельный Cloudflare Worker и закрытую Telegram-группу. Код, база и секреты чата не связаны с ботом Нафаней. Инструкция по настройке и проверке находится в [`support-chat-worker/README.md`](support-chat-worker/README.md).

## Поиск по сайту

Оранжевая лупа над чатом открывает поиск. Индекс `/site-search.json` собирается из опубликованного содержимого CMS; черновики, просроченные объявления, админка и переписка чата в него не попадают. Запрос обрабатывается в браузере, без передачи текста запроса стороннему поисковику или серверу. Новые записи из админки появляются в индексе автоматически (кэш браузера — до 60 секунд). Содержимое прикреплённых PDF и аудиозаписей не индексируется — доступны названия и описания на страницах сайта.
