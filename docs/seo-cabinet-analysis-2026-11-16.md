## Приоритеты роста и проверка результата

1. Согласовать главную: сокращение АА в title, международный онлайн-формат в description и короткий поясняющий абзац. Цель — соответствие спросу «онлайн-группа АА» и онлайн-части городских запросов. Не обещать позиции по каждому городу.
2. Согласовать шесть точных description по содержимому разделов. Длина — эвристика, а не самостоятельная цель и не гарантия CTR.
3. Согласовать переход со страницы Шагов к расписанию после официального материала: на текущей странице прямой ссылки schedule/Zoom при проверке HTML не найдено. Текст Шагов не менять.
4. Через 7–14 дней проверить статус двух запрошенных URL; сравнивать четыре недели после согласованных изменений с предыдущими четырьмя при доступной отчётности. Раздельно отслеживать релевантные показы/клики АА онлайн, расписания и страниц входа; PDF и английские запросы учитывать отдельно. Малую выборку и анонимизацию сохранять в выводах.
5. При восстановлении Яндекса снять свежую исходную точку, без фиктивного сравнения со старой сводкой.

Безопасных подтверждённых дефектов, требующих правки production-кода в этом кабинетном проходе, не найдено. Два запроса GSC выполнены; видимые изменения подготовлены, но ждут решения. SEO-автоматизация уточнена: прямой кабинетный доступ при ошибке коннектора, явные периоды, сокращение АА и международный онлайн-смысл; расписание и статус автоматизации сохранены.
