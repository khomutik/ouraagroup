# Еженедельная SEO-проверка — 2 ноября 2026

## Техническое состояние и поиск по сайту

- Главная, `/sitemap.xml` и `/robots.txt` доступны по HTTPS с HTTP 200; robots.txt разрешает обход и указывает публичную карту сайта.
- В sitemap 17 URL. Проверка всех 17 страниц: HTTP 200, 17 непустых уникальных title, description и self-canonical на каждой странице; noindex не найден. Ошибок проверки нет.
- JSON-LD найден на главной: один блок корректно разбирается как JSON. Данные разметки на других страницах не обнаружены.
- `/site-search.json` отвечает HTTP 200 и содержит 514 поисковых документов. Проверены запросы «расписание собраний», «тест на алкоголизм», «спикерские», «повестка РС» и «собрание АА онлайн»: поиск возвращает подходящие страницы расписания, новичкам, теста, спикерских и архива.
- Технических SEO-ошибок, требующих безопасного исправления, в этой проверке не выявлено. Код, видимые тексты, дизайн, аналитические настройки и production не менялись.

## Данные поиска и аналитика

- Подключённый SiteGuru MCP при запросе списка сайтов ответил `401 Unauthenticated`; поэтому через этот источник в текущем цикле недоступны свежие данные Google Search Console и Google Analytics 4.
- Google Search Console, Яндекс.Вебмастер и Bing Webmaster не предоставили в этой сессии авторизованные отчёты с запросами, показами, кликами, CTR, позициями и индексированием. Публичная страница Яндекс.Вебмастера открылась как страница входа/добавления сайта; страница Bing загрузила только оболочку, требующую JavaScript, без данных ресурса. Состояние кабинетов по этому признаку не оценивается.
- На странице Wordstat отображается сообщение Яндекса о временной недоступности части данных. Новые частотности и тренды за текущий период не получены.
- Срезы GSC/Метрики от 26 октября и Wordstat из исследования от 5/12 октября являются историческими; они не выдаются за показатели этой недели. Из-за отсутствия свежих сопоставимых данных динамика не рассчитывалась.

## План роста до восстановления данных

1. Получить актуальные отчёты кабинетов и реальные частоты Wordstat после восстановления доступа. Приоритет — соответствие поискового намерения существующим страницам: «АА онлайн / расписание» → главная и расписание; «спикерские АА» → страница аудиозаписей; вопросы новичков → существующий раздел новичкам; запросы с намерением пройти тест → имеющаяся страница с вопросами АА, не медицинская диагностика.
2. На свежих данных сравнить показы, клики, CTR и позиции по этим кластерам, отдельно проверить запросы с показами без кликов и страницы, которые уже получают релевантные переходы. Частотности и возможный эффект не прогнозировать без данных.
3. Тексты официальной литературы АА остаются неизменными. Любые новые видимые тексты, заголовки, описания или материалы до публикации представить владелице на утверждение.

## Необходимое действие

Для следующего полного кабинетного сравнения требуется восстановить авторизованный доступ к SEO-источникам. Первым препятствием является ответ SiteGuru `401 Unauthenticated`; следует переподключить SiteGuru в Codex либо предоставить рабочую авторизованную сессию Google Search Console. Свежие данные Яндекса и Bing после входа также пока не получены.
