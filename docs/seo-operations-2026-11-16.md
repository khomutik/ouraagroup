## План роста

1. После восстановления кабинетного доступа получить два одинаковых полных периода с учётом задержки отчётности. Сначала сравнить кластеры «АА онлайн/расписание», вопросы новичков, спикерские и тест; определить фактические страницы входа и нерелевантные запросы.
2. По этим данным выбрать страницы с показами без кликов и предложить точечные изменения метаданных и внутренних переходов. Показатели проверки результата: релевантные показы, клики, CTR и позиции по тем же кластерам; прогнозы роста без данных не делать.
3. Отдельная техническая гипотеза для следующей согласованной доработки поиска: общую страницу расписания показывать перед архивными обсуждениями при запросе расписания. Изменение выдачи не внесено.
4. Официальная литература АА неизменяема. Любые видимые тексты, заголовки, описания, новые материалы или дизайн требуют конкретного предложения и решения владелицы. Медицинские намерения поиска не используются для обещаний лечения.

## Уточнение внутренней проверки и выпуска

Повторная проверка графа ссылок завершена: все 17 страниц sitemap имеют входящие HTML-ссылки с проверенных страниц; при повторе ошибок загрузки нет. В первом проходе одна загрузка превысила таймаут, постоянный сбой не подтвердился.

После записи журнала GitHub CI выявил устаревшее ожидание в live-тесте поиска: общий запрос «правила чата» требовал мартовскую повестку среди первых трёх, хотя индекс пополнился новыми релевантными обсуждениями. Мартовская повестка остаётся в выдаче (шестое место). Скорректирован только тест: общий запрос должен вернуть релевантную повестку среди первых трёх, мартовская запись отдельно должна оставаться доступной в полной выдаче. Конкретные даты продолжают проверяться отдельными датированными сценариями. Алгоритм поиска и порядок результатов, материалы, приватность и настройки сайта не изменены.
