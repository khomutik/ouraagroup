# Резервная копия нового сайта

Сайт и настройки Caddy на VPS #1063655 копируются в зашифрованный архив `*.tar.gz.age`.
Скрипты: `scripts/backup-new-site.sh` и `scripts/run-backup-new-site.ps1`.
Запуск по расписанию — ежемесячная задача Codex «Ежемесячный зашифрованный бэкап сайта ПН».

Архивы сохраняются в `OneDrive/Резервные копии серверов/VDSina/Новый сайт`.
Успешное создание локального файла не доказывает, что OneDrive завершил загрузку:
проверяйте состояние синхронизации и наличие конкретного архива в облаке.

Ключ расшифровки хранится **отдельно от OneDrive и GitHub** в
`C:\Users\mtomb\AppData\Local\PNBackup\site-backup-identity.txt`.
Нужна ещё одна безопасная офлайн-копия ключа: без него архив не восстановить,
если компьютер выйдет из строя. Не отправляйте содержимое ключа в чат.

После создания скрипт сам расшифровывает архив в поток и проверяет список TAR.
Это проверка читаемости копии, но не полноценный тест запуска восстановленного сайта.
Первый архив от 05.10.2026 был также распакован во временную папку: основные файлы
сайта, данные CMS и настройки Caddy обнаружены; временная распаковка удалена.

Для восстановления нужен ключ, `age` и `tar`. Работайте с копией архива в отдельной
временной папке, не поверх действующего сайта:

```bash
age -d -i /path/to/site-backup-identity.txt site-backup.tar.gz.age | tar -tzf -
```

Команда показывает содержимое, ничего не меняя на сервере. Полное восстановление
на VPS требует отдельной проверки конфигурации и ручного переключения сайта.
